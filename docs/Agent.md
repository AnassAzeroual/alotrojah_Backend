## 3. Pedagogy (do not re-ask; from questions.md meeting)
- Student types: children +4 / adults +18; modes per student: thumn (1 hizb=8 thumn; rubu/nisf variants) OR surah+ayah range. `term_plans.plan_mode` carries both (from/to).
- 3 sessions/week default (Mon/Wed/Fri, editable `groups.schedule_days`); weekly goal completion, not day counting.
- Teacher types share one entry page, fields toggled by `teacher_type`: hifz (hifz/tajwid/mowathaba/sarraj per session) vs murajaa (ONE official /20 per 1–3-week cycle).
- Calendar template: 6 terms × 7 weeks (6 study + 1 review/quiz) = 42 weeks/126 sessions, generated by Laravel button, fully editable; any term count allowed.
- Delegation: responsible teacher generates token link (15/30/60/120 min) sent via WhatsApp; another teacher redeems and enters marks.
- Announcements audiences: `all/teachers/manager/my_students`. Honor board (تشجيع/انتبه) by teacher+manager; gifts, family called, notes via WhatsApp.
- Mobile-first, Arabic-first; cross-center comparison pages allowed (PDF/image + WhatsApp share); reports printable like book.

## 4. Scoring (locked)
- Weekly /20 = SUM of active weekly-total modules. Default hifz 14 + mowathaba 4 + tajwid 2; manager rebalances (must sum 20) on manager-only page.
- New books = new `scoring_modules` rows. Sarraj (السراج): per-session like hifz but **separate /20** (`is_in_weekly_total=0`), weekly avg = mean of session /20s; inactive modules grayed + excluded everywhere (`is_active=1`).
- Mowathaba /4 MANUAL per session; never derived from `attendance` (independent register).
- Murajaa official /20 from `murajaa_reviews` cycles only (old qualitative scale dead); `revision_logs` = optional practice.
- Final = `(avg_murajaa + avg_weekly + Σ term quiz avgs incl. final) / (2 + n_terms)` (6 terms → ÷8); from `v_student_season_avgs` + `v_term_quiz_avgs`; never hardcode.
- Exams: flexible count, questions generatable from thumn/hizb start ayat, teacher/manager reorders.
